## Como executar o projeto?
1. Clone o repositório
```bash
git clone https://github.com/Flask-Web-Development/2026-ppi-Jade-Raquel.git
```
2. Acesse a pasta do repositório
```bash
cd .\2026-ppi-Jade-Raquel\
```
3. Agora selecione o repositório do projeto que deseja executar(exemplo: Site de avaliar músicas)
```bash
cd .\src\avalie-musicas\
```
Dentro da pasta do projeto, siga seu próprio `README.md`
